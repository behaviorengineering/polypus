Operator pack for the Polypus inference gateway module.

**Minimal prompt:**

> Wire Polypus ai-copilots using BOOTSTRAP.md

The homelab still deploys from gitlab.com/xynova/polypus-local until it switches to `polypus deploy`; load [skills/polypus-operator/windows-gitlab-deploy.md](skills/polypus-operator/windows-gitlab-deploy.md) for that path.
